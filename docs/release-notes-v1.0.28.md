# PS 切图工具 v1.0.28

## 本版重点

- 图层组可直接作为输入，递归处理组内可见末级图层。
- 默认导出 PNG-only，不再在素材目录生成 JSON 清单。
- “合并选中图层后处理”支持先合成再拆分的工作流。
- 保留按内容、按选区、按参考线、智能拆分、严格拆分、固定尺寸和偶数尺寸输出。
- 校对窗口支持真实缩略图、选择结果、合并、拆分、忽略和应用结果。
